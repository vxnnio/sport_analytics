## AI Motion Analysis (Team Contribution)

This project also includes an AI-based motion analysis module developed as a team effort.

The module uses computer vision techniques to analyze human movements during training.

### Technologies Used

- YOLO (You Only Look Once) for object detection
- MediaPipe for pose estimation
- OpenCV for video processing

### Features

- Real-time human pose detection
- Keypoint tracking (e.g., joints, limbs)
- Movement analysis for training evaluation
- Potential use for posture correction and performance improvement

### My Role

In this project, I mainly focused on:

- Backend system development using Flask
- Database design and integration (MySQL + SQLAlchemy)
- Implementing user authentication and role-based access control
- Developing coach announcement system
- Integrating system modules and ensuring overall system stability

The AI motion analysis module was primarily developed by other team members, while I assisted in system integration and understanding data flow between modules.
